# 书单资料库

本仓库用于保存个人阅读书单对应的电子书、书目元数据、来源与授权记录。

## 当前书目范围

- 用户上传的书单：205 本
- 额外明确指定：《传习录》1 本、《毛泽东选集》第一至第五卷 5 本
- 合计：**211 本**，分别以独立记录建档
- 完整书目见 [catalog/booklist.csv](catalog/booklist.csv)

## 采集原则

1. 优先采集公版原著、明确开放许可全文、权利人授权全文。
2. 对无法确认再分发许可的作品，不把第三方仓库的存在或仓库代码许可证当成作品授权；保留书目信息、来源和合法获取入口。
3. 每本书记录具体版本、作者/译者、语言、来源 URL、许可依据、采集状态和校验信息。
4. 公版判断按具体版本、译本和适用司法辖区分别记录；原著公版不代表现代译本也公版。
5. 不把目录、网页链接、节选或不完整文本标记为已采集全文。

## 目录约定

- `catalog/`：原始书单与标准化书目清单
- `books/`：已确认可合法镜像的电子书
- `sources/`：来源、许可与采集记录
- `metadata/`：结构化元数据
- `scripts/`：来源采集脚本

## 采集流程

书目确认 → 版本确认 → 来源与许可核验 → 下载 → 完整性校验 → 入库。
