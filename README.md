# 书单资料库

本仓库用于保存书单中的电子书、书目元数据、来源与授权记录，供个人阅读和后续阅读系统导入。

## 采集原则

1. 仅镜像公版文本、明确开放许可内容，或已取得权利人授权的全文。
2. 对仍受版权保护且未获授权的书籍，不上传盗版扫描件、网盘文件或未经许可的全文；保留书目信息及出版社、图书馆、作者官方页面等合法获取入口。
3. 每本书记录版本、语言、来源 URL、许可依据、采集状态和校验信息。
4. 公版判断按具体版本、译本和适用司法辖区分别记录；原著公版不代表现代译本也公版。
5. 采集文件尽量保留来源文本，不擅自改写；清洗、OCR、格式转换另存并记录处理过程。

## 目录约定

- `catalog/`：原始书单与标准化书目清单
- `books/`：已确认可合法镜像的电子书
- `sources/`：来源、许可与采集记录
- `metadata/`：结构化元数据
