# 书单资料库

本仓库用于保存用户书单对应的电子书、书目元数据、来源与授权记录，供个人学习和阅读系统导入。

## 采集原则

1. 优先采集公版原著、明确开放许可全文、权利人授权全文。
2. 对无法确认再分发许可的作品，不把第三方仓库的存在或仓库代码许可证当成作品授权；先保留书目信息、来源和合法获取入口。
3. 每本书记录具体版本、作者/译者、语言、来源 URL、许可依据、采集状态和校验信息。
4. 公版判断按具体版本、译本和适用司法辖区分别记录；原著公版不代表现代译本也公版。
5. 不把目录、网页链接、节选或不完整文本标记为已采集全文。

## 目录约定

- `catalog/`：原始书单与标准化书目清单
- `books/`：已确认可合法镜像的电子书
- `sources/`：来源、许可与采集记录
- `metadata/`：结构化元数据
- `scripts/`：来源采集脚本
